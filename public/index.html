语音模型与配音 API

课程逐句配音，自动进入材料库和跟读练习。建议先配置云端语音 API；本机 IndexTTS 2.5 放到最后联调。

先填 Key，再点“测试云端语音”确认接口可用；测试只播放一句，不会写入材料库。

如需使用 IndexTTS，请先在 Yovoice 中开启“本地 API”，再连接。

语音识别与跟读分析

系统会先使用浏览器识别；连接开发板时可改用云端转写。云端只接收本句录音，用于返回“听到了哪些词”，不等同于专业音素评分。

默认使用浏览器识别；开发板录音接入云端转写后也能自动分析。
